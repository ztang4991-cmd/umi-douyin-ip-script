# Mamba Banquet System v0.1

婚宴门店核心作战链试运行版：线索 -> 查重 -> 销售跟进助手 -> 商机 -> 档期 -> 订单 -> 合同/收款 -> 返佣统计 -> 老板看板。

## 技术选型

- 后端：Python 标准库 `http.server` + SQLite
- 前端：原生 HTML/CSS/JavaScript
- 存储：`data/mamba.sqlite3`
- 合同上传：`uploads/<tenant_id>/order-*.pdf`

选择这个方案是为了 v0.1 能在本地低依赖试运行，优先保证真实数据闭环、租户隔离、档期冲突校验和业务验收。

## 启动

```bash
python server.py
```

打开：

```text
http://127.0.0.1:8765
```

默认账号：

```text
老板：owner@mamba.local / owner123
销售：sales@mamba.local / sales123
```

也可以在登录页创建新门店和老板账号。

## v0.1 已覆盖

- 多租户、登录、角色基础权限
- 客资 CRM：新增、列表、详情、跟进、公海、协作人数据模型、第三方推荐字段
- 基础查重：手机号、微信号、姓名 + 婚期
- 线索转商机、商机转订单
- 销售跟进助手：意向等级、心理阶段、关注点、异议、话术模板、跟进节奏、超期提醒
- 档期管理：宴会厅/包间、正餐/试菜/临时锁台，同资源同日期同时间段唯一占用
- 订单：状态、合同 PDF、收款、第三方渠道继承、返佣比例/金额/状态
- 老板看板：销售、客资、订单、第三方成交额/占比、预计返佣、返佣成本率，并可下钻到明细页

## 红线

销售助手只做辅助建议：

- 不自动替销售决策
- 不自动发送
- 不自动报价
- 不自动承诺档期
- 不自动承诺优惠
- 不自动判定返佣归属
